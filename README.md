# Agentic AI

Hands-on implementations and experiments for learning **Agentic AI**.

## 🎯 What This Repository Is

This repository explores how LLMs can move beyond simple question-answering systems and become applications that can:

- Reason about a task
- Use tools
- Maintain context
- Make decisions
- Execute multi-step workflows
- Coordinate multiple agents

## 🧠 Topics

- LLMs
- Agents
- Tool calling
- Function calling
- Agent memory
- Structured outputs
- RAG
- Planning
- Agent orchestration
- Multi-agent systems
- Human-in-the-loop workflows

## 🔄 Learning Approach

```text
Concept
  ↓
Small implementation
  ↓
Debug
  ↓
Improve
  ↓
Build a complete application
```

## 🚀 Getting Started

```bash
git clone https://github.com/imvimalsharma/Agentic_AI.git
```
